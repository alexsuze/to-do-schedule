## 決策與備註
- Spring Boot 原定 3.x，因 Spring Initializr 只提供 4.x 改為 4.1.1（需求書已更新）。
- Quasar 使用 `@quasar/vite-plugin` 而非 Quasar CLI，`sassVariables` 需用 `fileURLToPath` 絕對路徑，否則 Windows 上找不到檔案。
- Railway 健康檢查用 `/actuator/health/liveness`，避免 Mongo 狀態影響。
- API JSON 欄位採 snake_case（`spring.jackson.property-naming-strategy=SNAKE_CASE`），與 Mongo 欄位一致，前端直接使用 `is_done_type`、`last_view_mode`。
- 後端錯誤以 `ResponseStatusException` 帶中文 message，`server.error.include-message=always`，前端 store 直接 Notify 顯示。
- Railway 部署踩雷紀錄（2026-09-09）：
  - `backend/mvnw` 需在 git 標記可執行（`git update-index --chmod=+x`），否則 Linux 建置 Permission denied。
  - Nixpacks 預設 JDK 17，需 `backend/nixpacks.toml` 指定 `jdk21`。
  - Spring Boot 4 的 Mongo 連線屬性改名為 `spring.mongodb.uri`（舊的 `spring.data.mongodb.uri` 會被忽略而連 localhost）。
  - `MONGODB_URI` 必須含資料庫名稱（`.net/todo_schedule?...`），另以 `spring.mongodb.database` 設預設值保險。
