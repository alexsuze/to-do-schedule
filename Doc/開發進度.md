## 決策與備註
- Spring Boot 原定 3.x，因 Spring Initializr 只提供 4.x 改為 4.1.1（需求書已更新）。
- Quasar 使用 `@quasar/vite-plugin` 而非 Quasar CLI，`sassVariables` 需用 `fileURLToPath` 絕對路徑，否則 Windows 上找不到檔案。
- Railway 健康檢查用 `/actuator/health/liveness`，避免 Mongo 狀態影響。
- API JSON 欄位採 snake_case（`spring.jackson.property-naming-strategy=SNAKE_CASE`），與 Mongo 欄位一致，前端直接使用 `is_done_type`、`last_view_mode`。
- 後端錯誤以 `ResponseStatusException` 帶中文訊息，啟用 `spring.mvc.problemdetails.enabled=true`（Spring Boot 4 的 `server.error.include-message` 不會帶出 reason），訊息在回應 `detail` 欄位，前端 store 直接 Notify 顯示。
- 拖曳採 `vuedraggable@4`（Quasar 無列表拖曳元件）。draggable 需要可變陣列，頁面用本地副本（`columns`、`lists`），store 變動時重建。
- 事項移動後直接重新載入整個看板的事項（其他卡片 order 也會變），資料量小不做局部更新。
- 日期時間顯示與輸入以瀏覽器時區處理，設定檔時區留到階段 5。
- 通知：全域總關閉時排程器不寄也不取消，pending 留著等再開啟；預設提前時間改了不回溯既有 pending（ponytail，需要時再加「重算全部」）。
- 每日摘要與提醒的時間顯示用 settings.timezone；前端顯示仍用瀏覽器時區（單人使用兩者通常相同）。
- 前端純函式測試用 Node 20 內建 `node --test`（`npm test`），不裝測試框架。
- 時程表用純 CSS 繪製（每天 48px），不加甘特圖套件。原設計的日 / 週 / 月切換依使用者要求改為固定 30 天 + 兩端擴展。
- 開始日期依使用者要求改為含時間（`start_at`），與到期一致；輸入用 Quasar `q-date` + `q-time`（24 小時制），只選日期時開始預設 09:00、到期預設 18:00。
- Spring Boot 4（Jackson 3）：接收 JSON 的 class 只能有一個建構子，否則整個請求 400「Failed to read request」；`Board.Column` 改用 `Column.of(...)` 靜態工廠。
- 不啟用 `spring.data.mongodb.auto-index-creation`：會讓本機沒 Mongo 時無法啟動；資料量小暫不建索引。
- Railway 部署踩雷紀錄（2026-09-09）：
  - `backend/mvnw` 需在 git 標記可執行（`git update-index --chmod=+x`），否則 Linux 建置 Permission denied。
  - Nixpacks 預設 JDK 17，需 `backend/nixpacks.toml` 指定 `jdk21`。
  - Spring Boot 4 的 Mongo 連線屬性改名為 `spring.mongodb.uri`（舊的 `spring.data.mongodb.uri` 會被忽略而連 localhost）。
  - `MONGODB_URI` 必須含資料庫名稱（`.net/todo_schedule?...`），另以 `spring.mongodb.database` 設預設值保險。
