## 決策與備註（沿用的部署經驗）
- Quasar 使用 `@quasar/vite-plugin` 而非 Quasar CLI，`sassVariables` 需用 `fileURLToPath` 絕對路徑，否則 Windows 上找不到檔案。
- Railway 健康檢查用 `/actuator/health/liveness`，避免 Mongo 狀態影響。
- API JSON 欄位採 snake_case（`spring.jackson.property-naming-strategy=SNAKE_CASE`）。
- 後端錯誤以 `ResponseStatusException` 帶中文訊息，啟用 `spring.mvc.problemdetails.enabled=true`，訊息在回應 `detail` 欄位。
- Spring Boot 4（Jackson 3）：接收 JSON 的 class 只能有一個建構子，否則整個請求 400。
- 不啟用 `spring.data.mongodb.auto-index-creation`：會讓本機沒 Mongo 時無法啟動。
- Resend 寄件者 `onboarding@resend.dev`，只能寄到 Resend 帳號的 Email。
- Railway 部署踩雷紀錄：
  - `backend/mvnw` 需在 git 標記可執行（`git update-index --chmod=+x`），否則 Linux 建置 Permission denied。
  - Nixpacks 預設 JDK 17，需 `backend/nixpacks.toml` 指定 `jdk21`。
  - Spring Boot 4 的 Mongo 連線屬性為 `spring.mongodb.uri`（舊的 `spring.data.mongodb.uri` 會被忽略而連 localhost）。
  - `MONGODB_URI` 必須含資料庫名稱（`.net/todo_schedule?...`），另以 `spring.mongodb.database` 設預設值保險。
