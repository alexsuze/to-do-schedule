# 工作事項管理系統 需求書

- 版本：v1.0 草稿（2026-10-28，打掉重練後的新版）
- 使用者：單人
- 核心概念：**任務紀錄 + 工時紀錄**。任務以卡片管理；把卡片拖進每 30 分鐘一格的週時程表，排在表上的時段就是工時。

標「暫定」的項目是使用者沒特別指定、先採最簡單做法的部分，確認後拿掉標記。

---

## 1. 頁面總覽

| 頁面 | 用途 |
|------|------|
| 任務 | 建立、編輯、完成任務卡 |
| 時程表 | 週檢視，把任務拖進時段、拉長縮短調整工時 |
| 統計 | 工時、完成狀況、分類統計 |
| 回收桶 | 已刪除的任務，可還原或永久刪除 |
| 設定 | 分類管理、Email 摘要設定 |

左側選單切換頁面。

**深色 / 淺色模式**：頁面上方有切換按鈕，可在深色、淺色之間切換，所有頁面一起套用。選擇記在瀏覽器裡，下次打開維持；第一次打開時跟隨電腦系統的設定。

## 2. 任務卡

### 2.1 欄位
| 欄位 | 必填 | 說明 |
|------|------|------|
| 標題 | 是 | 1～100 字 |
| 描述 | 否 | 多行文字 |
| 分類 | 否 | 從設定的分類中選一個（2.3），卡片顯示分類顏色 |
| 死線 | 否 | 日期 + 時間；只選日期時預設 18:00 |
| 子任務 | 否 | 多筆「checkbox + 名稱」，可新增、勾選、改名、刪除、拖曳排序 |
| 狀態 | — | 未完成 / 完成，新建預設未完成 |

### 2.2 任務頁
- 以卡片排列顯示，每張卡片顯示：標題、分類色、死線、子任務進度（例如 2/5）、累計工時（例如 3.5h）。
- 死線提示：24 小時內到期顯示警示色，已逾期顯示紅色。
- 切換「未完成 / 已完成 / 全部」；預設只看未完成。
- 排序：死線近的在前，沒死線的在後。
- 點卡片開編輯視窗；卡片上可直接勾選完成。
- 刪除：需確認，刪除後移到回收桶（見 2.4）。

### 2.3 分類
- 在設定頁管理：新增、改名、改顏色、刪除。
- 刪除分類時，屬於該分類的任務變成「未分類」，不會刪除任務。

### 2.4 回收桶
- 刪除的任務進回收桶；在回收桶期間，它的時段**不顯示在時程表、不計入統計、不佔用時間**（其他任務可以排進那段時間）。
- **還原**：任務回到任務頁，時段一起回到時程表。若某個時段在刪除期間已被其他任務佔用，該時段不還原並提示。
- **永久刪除**：可單筆刪除或「清空回收桶」，需確認；任務與它的時段一起刪除，無法復原。
- **自動清除**：進回收桶滿 30 天自動永久刪除，每天凌晨 03:00 執行。
- 回收桶列表顯示：標題、分類、刪除時間、剩幾天會被自動刪除。

## 3. 時程表

### 3.1 版面
- 週檢視：橫向 7 天（週一～週日），直向每 30 分鐘一格。
- 可切換上週 / 下週，「本週」按鈕回到這週；今天那一欄標示底色，並顯示目前時間線。
- 時段範圍：整天 00:00～24:00，**預設只展開 09:00～18:00**；上下兩端各有「展開更早 / 展開更晚」按鈕，點一下顯示前後其他時段。展開狀態記在瀏覽器裡，下次打開維持。每次展開 3 小時。
- 左側列出**未完成**的任務卡（小卡），可搜尋標題。
- 標示台灣國定假日與補班日（日期下方標籤＋放假日整欄底色），資料取自行政院人事行政總處辦公日曆的公開整理檔，讀不到時不標示。

### 3.2 操作
- **放入**：從左側把任務卡拖進格子，建立一個時段，預設 0.5 小時（1 格）。
- **調整工時**：拖曳時段的下緣延長或縮短，以 30 分鐘為單位，最短 30 分鐘。
- **移動**：拖曳時段本身換到其他時間或其他天。
- **刪除**：拖曳時段時畫面下方出現垃圾桶區，拖進去即移除（只刪時段，不刪任務）；移除後提示可「復原」。
- **同一任務可放很多次**，任務的累計工時 = 所有時段加總。
- 時段顯示任務標題與分類色；點時段開該任務的編輯視窗。
- 時段不可跨日（最晚到 24:00）。
- 時段不可重疊：放到已被佔用的時間會被擋下並提示（一個人同一時間只做一件事，統計才不會重複算）。
- 已完成任務的時段仍留在時程表上（顯示淡色），並計入統計。

### 3.3 工時意義
時段**不區分預計和實際**：先排程，實際有變動就拖曳調整，最後留在表上的就是工時。

## 4. 統計頁

- 期間選擇：本週 / 本月 / 自訂起訖日期。
- **工時總計**：期間內總工時；每天工時長條圖。
- **分類統計**：各分類工時佔比圓餅圖（含「未分類」），加上各分類小時數。
- **完成狀況**：未完成數、已完成數、逾期數（未完成且已過死線）、期間內完成數。
- 工時以時段的實際時間計算，例如 2 個時段各 1.5 小時 = 3 小時。

## 5. Email 每日摘要

- 每天固定時間寄一封摘要信，內容：
  - 今天到期的任務
  - 已逾期的任務
  - 今天時程表上排了哪些時段（時間 + 任務名）
  - 本週累計工時：週一到昨天（已經過去的天數）的工時加總，例如週三寄信只算週一＋週二；沒有工時（含週一）就不列此項。此項不影響「要不要寄」
- 三項都沒有內容時不寄。
- 設定頁：收件 Email、寄送時間（預設 08:00）、開 / 關、寄送測試信。
- 時區固定 Asia/Taipei。
- 寄件者 `onboarding@resend.dev`，只能寄到 Resend 帳號的 Email。

## 6. 資料結構（MongoDB，欄位 snake_case，時間以 UTC 存）

### tasks
| 欄位 | 型別 | 說明 |
|------|------|------|
| _id | ObjectId | |
| title | string | |
| description | string | |
| category_id | string / null | |
| deadline | Date / null | |
| subtasks | array | `{ id, name, done }`，陣列順序即顯示順序 |
| done | boolean | |
| completed_at | Date / null | 勾選完成時寫入，用於「期間內完成數」 |
| deleted_at | Date / null | 非 null 即在回收桶；滿 30 天自動永久刪除 |
| created_at / updated_at | Date | |

### time_blocks
| 欄位 | 型別 | 說明 |
|------|------|------|
| _id | ObjectId | |
| task_id | string | |
| start_at | Date | 對齊 30 分鐘 |
| end_at | Date | 對齊 30 分鐘，與 start_at 同一天 |

### categories
| 欄位 | 型別 | 說明 |
|------|------|------|
| _id | ObjectId | |
| name | string | |
| color | string | 例如 `#1976D2` |
| order | int | 顯示順序 |

### settings（單筆）
| 欄位 | 型別 | 說明 |
|------|------|------|
| email | string | 收件 Email |

| digest_time | string | `HH:mm` |

## 7. 開發階段

1. **任務卡**：任務頁、編輯視窗、子任務、分類管理、回收桶
2. **時程表**：週檢視、拖曳放入 / 延展 / 移動 / 刪除、展開時段
3. **統計頁**
4. **Email 每日摘要**與設定頁

每個階段完成就上線，由使用者實際操作驗證。
